# Codex Clinical — Frontend (v2)

فرونت اند معدّل بالكامل عشان يتكلم مع الباك اند الجديد (`clinical_rag_backend`).

## اللي اتغيّر

- **مفيش صفحة "رفع كتاب" خالص.** شيلت الـ upload panel من الشات لأن الملفات
  بقت بتتسجل جوه السيستم من الأدمن (project → documents)، مش عن طريق يوزر عادي.
- بنية الصفحات بقت: **المشاريع** → (لو أدمن: تسجيل/فهرسة مستندات) + **المحادثات**
  → **الشات** جوه كل محادثة.
- الشات بيعرض دلوقتي **الاستشهادات (citations)** مع المستند/القسم/الصفحة،
  **درجة الثقة** (High/Medium/Low/Insufficient Evidence)، وبيبيّن لما النظام
  **يرفض** يجاوب (أدلة غير كافية / سؤال خارج النطاق).
- `/auth/register` بقى محتاج **email** كمان (مطلوب من الباك اند).
- أول حساب يتسجل في السيستم بيبقى **أدمن** تلقائيًا (بيظهر بادج "أدمن" في الشريط الجانبي).

## الصفحات

| المسار | الوظيفة |
|---|---|
| `/login`, `/register` | تسجيل الدخول / حساب جديد |
| `/projects` | لستة المشاريع + إنشاء مشروع جديد |
| `/projects/:id` | تفاصيل المشروع: المحادثات + (أدمن) تسجيل/فهرسة المستندات |
| `/projects/:id/conversations/:conversationId` | الشات نفسه |
| `/profile` | تعديل اليوزرنيم/الباسورد |

## التشغيل

```bash
npm install
npm run dev
```

الافتراضي إنه بيكلم الباك اند على `http://127.0.0.1:8000` (لاحظ إن الباك اند الجديد
بقى الـ base path لكل حاجة تحته `/api/v1/...` عدا `/health` و `/ready`، وده متظبط
جوه `src/api/client.js` خالص، مش محتاج تغيّر حاجة في `.env` إلا لو غيّرت البورت).
